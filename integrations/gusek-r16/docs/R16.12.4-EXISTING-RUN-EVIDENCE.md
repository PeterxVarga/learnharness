# R16.12.4 – Korábbi Node 26 kvalifikáció bizonyítékainak egyeztetése

## Miért szükséges?

A 2026-10-31-i Fedora-futás (`learnharness-r1612-real-E2nwWZFs`) Node 26 alatt eljutott az upstream npm-tesztek, a Next production build, a szakmai GUSEK-tesztek és a loopback HTTP-tesztek végéig. Az eredeti futtató a legutolsó integritási kapun `exit=3`-mal megállt, mert a Next build módosította a **tracked** `next-env.d.ts` két generált importútvonalát. Az R16.12.3 ellenőrző már kizárólag a pontos, upstream 0.4.1-ből bizonyítható átírást fogadja el; a felhasználó meglévő összeállításán `R16_POSTBUILD_INTEGRITY=PASS` eredményt kapott. Ez nem írja át az eredeti futás exit kódját.

## Egyszeri, nem újrafuttató bizonyítás

A `resume-r1612-evidence.py` csak a meglévő workspace-t olvassa. Ellenőrzi az upstream és R15 pontos commitját és tiszta állapotát; az **R16.12.3 teljes forrás-, overlay- és csomaghash-ellenőrzőjét** változatlan formában hívja meg; a korábbi `qualification.log` szigorúan sorrendezett kapuit, Node 26 verzióját, az upstream `npm test` teljes TAP PASS-számait, a Next buildhez való továbbjutást, a pontos GUSEK HTTP PASS-t és az eredeti kizárólagos `next-env.d.ts` blokkolást egyezteti. Hibás, hiányos vagy összekevert napló, eltérő Git-commit, ismeretlen forráseltérés esetén **nem állít elő nyugtát**.

Példa az eredeti gépen, a pontos R16.12.4 commitból futtatva:

```bash
python3 integrations/gusek-r16/resume-r1612-evidence.py \
  --workspace "$HOME/Downloads/learnharness-r1612-real-E2nwWZFs" --write
```

A létrejövő `candidate/evidence/r16.12-reconciled-technical-evidence.json` csak **nem aláírt, külön technikai bizonyíték** (`TECHNICAL_GATES_RECONCILED_FROM_EXISTING_RUN`). Nem hoz létre `qualification.json` fájlt, nem módosítja az eredeti logot vagy a forrásokat, nem nevez egy eredetileg sikertelen futást `exit=0`-nak. Az egyszeri `--write` kizárólag új fájlra működik, és tulajdonosi olvasási/írási jogosultsággal hozza létre azt. Az npm tesztek, a Next build és a HTTP tesztek **nem futnak újra**.

- Az új parser saját 10 szintetikus/negatív tesztje PASS; a teljes, korábban lefutott E2E bizonyítéka csak az eredeti Fedora-környezetben áll rendelkezésre.

- Nem bizonyított: valódi natív GLPK, vizuális Chromium E2E, független review, npm sebezhetőségek kizárása, merge/release engedély.
- A `main`, az R15 draft PR és az eredeti upstream nem változik; `NO_GO` marad.
