# R16.12.6 — Independent mathematical-grading review

## Reproduced incorrect full-credit proofs
Assignment: `a11+a12+a13 = 1.000000005` has no binary solutions, but R16.12 returned MATCH with `delta=1e-8`.

Production: `2*alap+3*premium <= 11.999999999` excludes integer point `(0,4)` admitted by `<=12`. The R16 lattice proof returned UNASSESSABLE; the optional R14 halfspace fallback returned MATCH and could grant full points.

## Fix
Assignment exhaustion uses only bounded safe integer coefficients and exact equality; fractional coefficients/bounds return UNASSESSABLE. The approximate R14 proof is no longer allowed as a FULL_CREDIT fallback for either integer task when the exact domain proof cannot establish equivalence. The original R15 MathProg parser remains the sole parser. Correct integer row scaling, reordering and redundancy remain accepted. Some correct fractional rewrites now get UNASSESSABLE, never 0 by unsupported assumption.
