- In the owner's `npm audit --json`: **23 moderate affected package entries** are transitive consequences of this **one advisory**, rather than 23 distinct root advisories. Ten affected minimatch copies in the exact pinned lockfile were marked `dev:true` (versions 3.1.5, 5.1.9, 9.0.9, 10.2.6).
- The advisory concerns excessive CPU/memory from specially crafted glob patterns, with a precondition tied to pattern-processing behavior. Version-range matching **does not by itself prove all older major lines use the same exploitable code path**. Do not claim a safe exploitability conclusion from this inventory alone.
- Risk-reduction for a local internal pilot: run only owner-trusted development commands and glob inputs; bind Next to loopback; do not accept arbitrary user-controlled pattern input into build/lint packaging tools; isolate external files. In a shipped distribution, **reassess and resolve the vulnerability on compatible upstream dependency paths**, not via blanket `npm audit fix --force` or incompatible `minimatch@11` override.
- **Residual-risk approval is NOT recorded.** Proposed acceptance for a local pilot is a decision for the owner, not a fact conferred by this report.
