# R16.12.5 — Node 26 tesztösszesítő formátumainak egyeztetése

## Megfigyelt hiba
A korábbi Node 26 Fedora-kvalifikáció integritási ellenőrzése a teljes Next/GUSEK/HTTP-futás után PASS lett. A külön R16.12.4 bizonyíték-egyeztető azonban `NPM_TEST_SUMMARY_MISSING_OR_AMBIGUOUS: tests` blokkolást adott; a saját szintetikus tesztjei eközben 10/10 PASS-t mutattak.

**Ok:** a régi parser csak a `# tests 3187`, `# pass 3187`, `# fail 0` TAP-összesítést ismerte. A Node 26 interaktív/spec reporter ehelyett a `ℹ tests 3187`, `ℹ pass 3187`, `ℹ fail 0` jelölést használhatja. Az eredeti felhasználói Node 26-kimenetben a célzott GUSEK-tesztek összesítése már `ℹ tests 257` formában látszott; a teljes npm-napló még külön, a Fedora gépen ellenőrzendő.

## Szűk javítás
A `resume-r1612-evidence.py` ugyanabból az egyetlen **npm test és build közötti** logszegmensből egyetlen teljes TAP (`#`) VAGY spec (`ℹ`) hármast fogad el; a reporternek egyeznie, a sorrendnek `tests → pass → fail`-nek kell lennie. Átenged ANSI színezést, de nem enged duplikált, kevert, töredékes vagy hibás összesítőt; elutasítja a `not ok` / `✖`/`✘` markerrel jelölt hibát, illetve ha `pass != tests` vagy `fail != 0`.

A pontos Git-pinek, pack/assembly hash-ellenőrzés, források tiszta állapota, build/HTTP marker és az eredeti `exit=3` bizonyítása **változatlan**. A külön bizonyítéknyugta nem hivatalos `qualification.json` és nem release-engedély.

## Validáció
`tests/test_r1612_reconcile.py`: 16/16 célzott teszt helyben PASS, az új esetek között Unicode/spec reporter, ANSI, duplikáció, kevert formátum és hamis sikeres összesítőbe rejtett hiba. A *valódi Fedora napló* további ellenőrzése szükséges, itt nem állítjuk, hogy az új változat már PASS-t kapott rajta.

## Következő lépés
Futtassuk a javított scriptet az eredeti `learnharness-r1612-real-E2nwWZFs` munkaterületen. **Semmilyen npm-, Next.js- vagy GUSEK-tesztet nem kell újra futtatni**; csak a rögzített bizonyítékok kerülnek ellenőrzésre. A független review, vizuális E2E, natív GLPK és dependency-audit külön NO_GO kapuk maradnak.
