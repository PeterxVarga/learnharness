# LearnHarness R16.8 — User-controlled GUSEK → teaching handoff

2026-10-31. Reuse existing R15B corrective advice and the existing LearnHarness teacher; no new teaching agent, score authority or backend.

## User-facing behavior

On the *existing* R15 Workbench grade panel, an optional `Folytatás a LearnHarness tanítóval` disclosure presents a structured Hungarian tutoring brief. The learner can copy it, open a normal LearnHarness teaching chat and explicitly paste it. The UI does not auto-send any data, mutate the chat/graph, start a solver, save a new attempt or award points. The initial handoff is based on the R15 server result (0/1/null) and R15B diagnosed steps. It explicitly asks the teacher to wait for the student's reasoning, test prerequisite understanding and withhold the completed model and optimum. All teaching/evaluation beyond the handoff still belongs to the original LearnHarness and R15 server-side grade endpoint.

The handoff has different paths for **repair**, **unassessable**, and **transfer after 1/1**. An unassessable source is never called mathematically wrong. Self-reported absence of assistance is never certified as independence or mastery. The output never serializes source `.mod`, `.dat`, values, objective, GLPK token, chat ID, attempt ID or private learner data.
